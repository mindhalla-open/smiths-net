## Install

```bash
cargo install smiths-net
```

Or build from source:

```bash
git clone https://github.com/friday-mindhalla/smiths-net.git
cd smiths-net
cargo build --release
```

## Generate a config

```bash
smiths-net init --preset dev --non-interactive
```

This creates a `config.toml` with development defaults: debug logging,
no TLS, no auth, no sandbox.

## Start the engine

```bash
smiths-net --config config.toml
```

You should see:

```
INFO smiths_net: SIP UAS listening on udp://0.0.0.0:5060
INFO smiths_net: health endpoint listening addr=127.0.0.1:8080
```

## Verify

```bash
curl -s http://127.0.0.1:8080/health | jq .
```

## Place a test call

Using `pjsua`:

```bash
pjsua --null-audio --local-port=6070 sip:test@127.0.0.1:5060
```

## Talk through your computer

The bundled **`smiths-softphone`** client captures your microphone,
G.711-encodes it into RTP, and plays the peer's audio through your
speakers — no external softphone required. The "server" is whoever runs
the engine; everyone else runs the softphone.

```bash
# validate your mic → speaker chain (no network)
cargo run -p smiths-softphone -- loopback

# two people, one room — bridged by the engine
cargo run -p smiths-softphone -- call --engine 127.0.0.1:5060 --room demo
```

Use headphones — there is no echo cancellation yet.

## Group call (conference)

Set a **conference-room prefix** on the engine, then everyone who dials
a room under that prefix is mixed into one N-party call instead of a
2-peer bridge:

```bash
SMITHS__SIP__CONFERENCE_PREFIX=conf smiths-net --config config.toml
# each participant, in their own terminal / machine:
cargo run -p smiths-softphone -- call --engine 127.0.0.1:5060 --room conf-standup
```

Rooms that don't match the prefix keep the classic 2-peer bridge. You
can also manage conferences over MCP (`create_conference`,
`join_conference`).
