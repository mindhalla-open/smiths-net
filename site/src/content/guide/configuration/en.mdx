## Overview

Smiths-Net uses a layered configuration system: **defaults → TOML file → environment variables**.

Environment variables use the `SMITHS__` prefix with double-underscore nesting:

```bash
SMITHS__OBSERVABILITY__LOG_LEVEL=debug smiths-net --config config.toml
```
